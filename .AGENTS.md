# Ortenau Guesser is a game like the popular GeoGuessr
- It is fixed explicitly to the region Ortenau, Baden Wuerttemberg, Germany
- It uses OpenStreetmap for the Geoservices by using the OpenStreetmap API
- the game shoud be written in classic html/css/js
- launchable through a docker-compose.yaml that lies in .

## Projectstructure
- Frontend (HTML, CSS)
- Backend (JavaScript)
- Backend/Geoservices (Openstreetmap services)
- config (docker)

## Gamerules/implementation
- first implementation shoud have a basic singeplayer without persistence
- there shoud be a main menü
- you get randomly dropped into a streetview that is fixed to a point with the possibility to look around freely but you cant move
- after setting your guess on a small map on the bottom right the real distance gets shown from the actuel location and the users guess
- the streetview shoud be limited to the region

### implementation
- Subagent frontend, does all the frontend
- Subagent backend, does the backend js and openstreetmap services
- Subagent docker, writes the docker file and chooses the right images

### infobroker
- findings between Agents can be written down in .marketplace.md the agent that writes must identify himself in the lines he wrote
